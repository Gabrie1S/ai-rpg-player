玩家请求执行因果推演/局势预判：$ARGUMENTS

> 注：本指令属于可选扩展模块 [`skills/causal-foresight/SKILL.md`](skills/causal-foresight/SKILL.md)，仅当当前世界包或主角设定包含推演/预判/侦探演绎类能力时生效。

1. 读取 `S/player/sheet.md` 中相关推演能力的等级与范围（`abilities`）。若角色未配置此类特殊能力，结合主角现有的专业技能与情报分析水平给出合理的战术评估。
2. 读取在场与相关 NPC 的角色卡（动机、秘密、认知）、`S/world/director.md` 及时间线内近期事件。
3. 严格按照 [`skills/causal-foresight/SKILL.md`](skills/causal-foresight/SKILL.md) 输出：
   - 展开 **2~3 条截然不同的行动因果链**（激进风险线 / 常规僵局线 / 破局生机线）。
   - **每条路径必须写明完整因果链**：主角采取什么行动 → 触发谁的反应或什么机制 → 最终导致什么局面，绝不打哑谜。
   - **高维干扰与信息屏障**：涉及阶位远高于主角的人物、核心反侦察屏障或未到揭示阶段的秘密时，写成合乎世界观逻辑的截断或噪点，把“在哪一步被截断”本身作为重要线索呈现。
4. 推演过程不推进游戏时间，结尾将选择权完全交还玩家。
