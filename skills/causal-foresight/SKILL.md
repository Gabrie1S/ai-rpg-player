# 因果推演与可能性预判技能 (Causal Foresight Skill — 可选模块)

> **适用范围**：本技能是**可选挂载模块**，不属于所有世界观的默认配置。仅当某个世界包（`packs/<pack_id>/`）或角色卡显式设计了“战术沙盘推演、情报预判、侦探演绎或因果窥探”类特殊能力时启用。

在文字角色扮演中，赋予主角“预判/推演未来可能性”的能力极易踩坑：AI 往往要么写成神棍式的蒙太奇碎片（打哑谜，玩家看完不知所云），要么直接剧透唯一结局（剥夺玩家的自由选择感）。本技能沉淀了经过实战验证的**因果链推演法则**。

---

## 1. 核心原则：写“因果链”，绝不写“蒙太奇碎片”

每次触发推演能力时，必须围绕当前局势或玩家指定的目标，展开 **2 至 3 条截然不同的行动路径（可能线）**。

- **展示完整因果逻辑**：每一条可能线必须是一段**前因后果清晰**的微缩推演（如果采取 A 策略 → 会触动 B 机制/人物反应 → 进而导致 C 局面 → 最终通向 D 结局）。
- **严禁意识流画面**：不要堆砌毫无逻辑关联的意象（如“一滴血落在地板上、远处钟声响起、黑影一闪而过”）。玩家需要的是**可据此做决策的逻辑支点**，而不是谜语。
- **三条路径的梯度分布**：
  - **路径一（凶险/激进线）**：直球冲突或贪图捷径，触发致命陷阱或强敌反扑，看清最大的风险源在哪里。
  - **路径二（僵局/常规线）**：按部就班行事，虽然暂时安全但错失关键窗口，或付出沉重代价仅换来惨胜。
  - **路径三（生机/破局线）**：利用某个容易被忽略的环境细节、人物弱点或时间差，找到一线破局契机（但同样伴随具体代价或苛刻条件）。

---

## 2. 边界与信息迷雾：屏蔽本身就是重要情报

推演能力绝不是全知全能的“上帝视角外挂”。它必须受到角色当前认知水平与目标层级的严格制约：

1. **认知锚点限制**：只能基于主角**已经亲眼所见、亲耳所闻或掌握实证**的线索向外推演。未知领域无法凭空算尽。
2. **高维干扰与断层即线索**：
   - 当推演涉及到远超主角当前层级的人物、核心机密或强力反侦察屏障时，推演画面应当在关键节点出现**合乎世界观逻辑的截断、噪点或反噬**。
   - **重要法则**：不要只写“推演失败”，而要通过**“在哪一步被截断”、“截断时的异常特征”**向玩家传递侧面情报（例如：推演到某位小人物打开保险箱的瞬间信号被军用级防火墙强行掐断，这本身就证明该小人物背后有大势力兜底）。

---

## 3. 代价与冷却约束

- **资源消耗与负荷**：每次启动深度推演都应伴随明确的剧本内代价（如精神负荷、算力过热、精力透支或时间流逝），并在状态栏或角色卡中如实反映。
- **冷却机制**：同一场景或同一事件节点未发生实质性变量更新前，连续重复推演不会刷出更多免费情报，只会加剧角色负荷。

---

## 4. 推演之后的留白：把选择权交还玩家

- 推演展示的是**“如果不加干预或按某条路走，可能发生的未来”**，绝不等于已经既定的事实。
- 推演结束时，主角回到现实时间点。叙述需干净利落地收束在当下感官，由玩家决定是采纳其中一条路径，还是利用推演中发现的盲点走出**第四条路**。
