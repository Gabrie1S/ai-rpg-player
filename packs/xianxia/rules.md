# 规则书（初稿）

世界观见 `setting.md`。标 **【待定】** 的还没定，数值都是初稿，玩起来再调。机器要读的数值在 `rules.yaml`，两边保持一致。

## 1. 判定

**不掷骰。** 主持人按下面的依据直接判定。不是每件事都要判定：只有结果不确定、成败有分量的**难关**才判定；日常小事按常理直接写。

### 判定依据

按重要程度排列：

1. **境界和实力差距**：硬约束。高两个大境界以上，正面对抗低方必败，除非有剧情手段（法宝、计谋、环境）。高一个大境界，低方极难取胜
2. **行动本身好不好**：计划是否合理、是否利用了环境和对方的弱点、时机对不对。聪明、有准备的做法应该得到更好的结果；鲁莽、想当然的做法就该吃亏
3. **准备和信息**：事先打听过、准备过、用一线天看过的，胜算更大
4. **人物关系和过往**：对方的好感、信任、敬畏，玩家以前做过的事（施过恩、结过仇、守过信），会影响别人怎么回应
5. **能力匹配**：功法、技能、灵根属性是否对路，属性克制（见第 2 节）
6. **代价**：玩家愿意付出什么（受伤、暴露、欠人情、花钱）

### 结果档位

| 结果 | 含义 |
| --- | --- |
| 大成功 | 成功，并有额外收获 |
| 成功 | 达成目的 |
| 代价成功 | 达成，但付出代价（受伤、暴露、欠人情） |
| 失败 | 没达成，局势变化 |
| 大失败 | 失败，并有严重后果 |

### 防止偏袒

- **你不站在玩家这边。** 判定要像一个公正的裁判，而不是讨好玩家
- 好结果是挣来的：只有行动确实出色、或有关系和准备撑着，才给成功或大成功
- 平庸的做法得到平庸的结果；明显鲁莽的做法应该失败
- 不要连续很多次都让玩家顺利过关。如果最近几次难关都成功了，回头检查自己是不是判宽了
- 失败不是剧情的终点：失败要带来新的局面和新的机会，而不是卡住

### 显示

难关在正文对应处显示一行，写明结果和主要原因：

`【难关】攀崖 → 失败：崖面湿滑，你手里只有一把柴刀`

### 一线天与判定

玩家发动一线天时，会看到三种可能的结局，按好坏排列（最好的那种最难达成）。之后玩家实际怎么做，决定落到哪一种：做法越好、准备越足、关系越近，越可能落到好的那种。

## 2. 属性与克制

七种属性：金、木、水、火、土（基础五行），风、雷（变异）。

| 属性 | 克 | 被克 | 生 / 助 | 特点 |
| --- | --- | --- | --- | --- |
| 金 | — | — | 生水 | 不克也不被克 |
| 木 | 土、风 | 火、雷 | 生火 | 根破岩土，密林挡风 |
| 水 | 火 | 土 | 生木、助雷 | 浇灭火焰，被堤坝所阻 |
| 火 | 木 | 水 | 生土 | 烈火焚木 |
| 土 | 水、雷 | 木、风 | 生金 | 筑堤拦水，大地引雷 |
| 风 | 土 | 木 | 生火、助雷 | 以柔克刚；辅助强，输出也不弱 |
| 雷 | 木 | 土 | — | 天雷劈木，被大地导走 |

克制关系要符合直觉，描写时让人一看就懂为什么。

**克制不绝对**：纯净灵根 +2 正好抵消被克的 −2，至纯灵根 +3 甚至能反压克制。

**金与无属性**：都不克制别的，也不被克制。两者的差异化【待定】。

### 风

风是攻守兼备的属性：辅助能力强，输出也不弱。风的攻击偏向**以柔克刚**：无孔不入、借力打力、以快打慢。

### 强力组合

同一人兼有两种灵根，或两人配合施展合击时：

| 组合 | 效果 |
| --- | --- |
| 风火 | 风助火势，攻势凶猛 |
| 风雷 | 风助雷行，迅疾无匹 |
| 水风 | 助雷；也是风水、玄学一脉的根基，偏向推演、占星、占卜 |

合击技能属性写作多个，如 `element: [风, 雷]`。施展时两种属性的相生 +1 计入修正。

## 3. 境界

境界写法：**大境界 + 等级**，等级用壹到玖，如 `炼气叁`、`金丹玖`。凡人没有等级。

| 境界 | 特点 | 寿元（约） |
| --- | --- | --- |
| 凡人 | 无修为，可练武道 | 70 |
| 炼气 | 引气入体，能用简单法术和法器 | 120 |
| 筑基 | 正式踏入仙途，能御器飞行 | 200 |
| 金丹 | 体内结丹，一方高手，门派长老级 | 500 |
| 元婴 | 碎丹成婴，元婴可离体，肉身毁了还能夺舍 | 1000 |
| 化神 | 能调动天地之力，一方霸主 | 2000 |
| 炼虚 | 传说级 | 3000 |
| 合体 | 传说级 | 5000 |
| 大乘 | 当世巅峰；之上是什么无人知晓 | 10000 |

**口语说法**：壹~叁 初期，肆~陆 中期，柒~捌 后期，玖 大圆满（临近突破）。

### 境界差距

**每个大境界都是质变。** 高一个大境界，在力量、速度、神识、寿元上都是碾压级的差距，描写要让人明显感觉到。同一大境界内，初期、中期、后期、大圆满也要有可感的差别。

### 修炼与突破

- **等级提升**：靠修炼时间积累，**每级都不快**。速度 = 基础时间 ÷ 根骨系数 ÷ 灵根契合 ÷ 功法品阶系数
- 基础时间（中等根骨、普通功法）【初稿】：炼气每级 3~12 个月；筑基每级 1~3 年；金丹每级 3~10 年；元婴及以上每级十年以上
- **大境界突破**（玖 → 下一境界壹）：必须有机缘（丹药、顿悟、特定经历）+ 突破判定。失败可能受伤、跌落等级，或留下隐患
- 典型关口：筑基要筑基丹；结丹的品质影响终身；元婴有心魔劫；化神有天劫【待细化】

### 境界差

| 差距 | 修正 |
| --- | --- |
| 同大境界，每高 3 级 | +1 |
| 高一个大境界 | +4 |
| 高两个大境界及以上 | 正面对抗低方直接失败，除非有剧情手段（法宝、计谋、环境） |

天才（纯净灵根、绝世根骨、高阶功法）的其他修正能弥补一部分差距，所以越小境界战斗可行，越大境界极难。

## 4. 灵根

灵根是一组属性，**每条灵根各有纯度**，写作 `{风: 至纯, 雷: 至纯}`。无灵根记为空 `{}`。

| 纯度 | 技能加成 | 修炼速度 | 稀有度 |
| --- | --- | --- | --- |
| 驳杂 | 0 | ×0.6 | 最常见 |
| 寻常 | +1 | ×1.0 | 常见 |
| 纯净 | +2 | ×1.5 | 罕见 |
| 至纯 | +3 | ×2.0 | 举世罕有 |

**灵根数量**：

| 类型 | 条数 | 修炼分散系数 | 稀有度 |
| --- | --- | --- | --- |
| 单灵根 | 1 | ×1.2 | 少见 |
| 双灵根 | 2 | ×1.0 | 少见 |
| 三灵根 | 3 | ×0.9 | 较常见 |
| 杂灵根 | 4~7 | ×0.75 ~ ×0.4 | 常见 |
| 变异灵根 | 含风或雷 | — | 极罕见 |

绝大多数人没有灵根。有灵根的人，灵根多为驳杂或寻常，纯净罕见，至纯举世罕有。

**灵根的作用**：

- **修炼**：速度 = 基础 × 功法所属属性那条灵根的纯度系数 × 灵根数量系数 × 根骨系数 × 功法品阶系数。功法属性不在自身灵根中则无法修炼（无属性功法除外）
- **技能**：每条已生效的灵根，都给对应属性的技能加成。纯净灵根专精，杂灵根面面俱到
- 杂灵根修炼慢，但能增幅多种属性的技能。剑修配剑修功法，若灵根带火和土，火系、土系相关技能也有不小的助益

### 隐藏的灵根

有些人的灵根不是表面那样：

- `linggen`：真实灵根
- `linggen_active`：当前已生效的部分，规则计算按它来；觉醒时更新，最终与 linggen 一致
- `linggen_shown`：世人和灵根检测看到的样子

## 5. 资质

两项，各分四级：下、中、上、绝世。

| 等级 | 根骨：修炼速度系数 | 根骨：突破判定 | 悟性：学习速度 |
| --- | --- | --- | --- |
| 下 | ×0.6 | −1 | 慢，熟练度提升困难 |
| 中 | ×1.0 | 0 | 正常 |
| 上 | ×1.5 | +1 | 快，偶有顿悟 |
| 绝世 | ×2.5 | +2 | 极快，易领悟神通 |

- 根骨还影响肉身潜力：根骨下等的人，属性难以达到该境界区间上限
- 悟性影响学功法、技能、熟练度提升的速度，以及顿悟和领悟神通的机会

## 6. 功法

**一人同时只修一部功法**，它是体内运转的一套系统，是修士的引擎。

| 维度 | 说明 |
| --- | --- |
| 属性 | 七属性之一，或无属性（多为体修、武道，凡人也可修） |
| 品阶 | 天、地、玄、黄四阶，每阶分上中下品，写作 `玄阶中品` |
| 倾向 | 法修、剑修、体修、佛修、玄修（推演、占卜、风水）、兼修、其他 |
| 成长 | 决定修炼时哪些属性涨得快：法修涨灵力，体修涨体魄，剑修兼顾灵力和体魄 |
| 上限 | 能修到的最高境界，如黄阶功法多止步筑基 |

- 品阶影响修炼速度、属性成长和境界上限，高阶功法常自带神通
- 功法修到上限，必须另寻更好的功法
- **换功法**代价大【初稿】：散功重修，跌落 1~3 个等级，耗时数月到数年，需过一次走火入魔判定。新旧功法同属性时代价减半

## 7. 技能

技能独立于功法，谁都能学。

| 维度 | 说明 |
| --- | --- |
| 类型 | 攻击、防御、身法、控制、辅助 |
| 属性 | 七属性之一，或无属性（纯武技） |
| 品阶 | 与功法同一套：天地玄黄，上中下品 |
| 熟练度 | 入门、熟练、精通、大成、圆满 |

**命名约定**：

- **术**：低阶，如火球术、御风术
- **诀、法**：中阶，如玄水诀
- **神通**：金丹以上才能掌握，常与高阶功法相伴，也有独一无二的本命神通
- **秘术、禁术**：罕见的特殊传承，不一定有代价，但常有苛刻甚至唯一的修习条件（见 setting.md）

## 8. 法宝与神识

**法宝品级**：法器（炼气~筑基）→ 灵器（筑基~金丹）→ 法宝（金丹~元婴）→ 灵宝（元婴~化神）→ 仙器（上古遗物）。

- 修士可温养**本命法宝**，与之心意相通，契合度高
- 法宝修正 0 ~ +2，看品级是否压过对手、与使用者是否契合

**神识**是四项属性之一，用于：察觉与探查、同时操控法宝的数量、抵抗幻术和夺舍、识破伪装。

| 神识 | 察觉、探查、控器、抗幻术、炼丹布阵 |

## 10. 战斗与伤势

- 战斗不逐回合判定，在关键节点判定 1~3 次，按结果描写
- 伤势：无伤 → 轻伤 → 重伤 → 濒死 → 死亡
- 重伤影响后续判定（−2），需要时间或丹药恢复
- 濒死：需要救援或一次判定，失败则死亡
- **主角可以死**。死后可用徒弟或后人传承继续【待定：传承规则】

## 11. 时间消耗

所有行动都消耗游戏时间，用 `clock.py advance` 推进。

| 赶路 | 按地点 `neighbors.days`（凡人脚程）；御器飞行等按比例缩短【待定】 |
| 闭关修炼 | 见第 3 节 |
| 炼丹、炼器、布阵 | 【待定】 |

## 13. NPC 态度

- 三个维度：好感（喜不喜欢）、信任（信不信）、敬畏（怕不怕），范围 −100 ~ 100
- 变化幅度：小事 ±3，中事 ±10，大事 ±25
- 性格系数写在 NPC 卡 `traits_effect`，结算时照着算（如"记仇：负面 ×2"）
- 阈值写在 `thresholds`，达到即解锁内容

## 14. 天赋能力

少数人有与生俱来的特殊能力，记在角色卡 `abilities` 里：`{name, level, notes}`。

### 一线天（主角）

主角与生俱来的能力：从一线缝隙里窥见某个选择在一定时间内的后果，只有一线，转瞬即逝。玩家用 `/yixiantian` 或直接说要发动一线天，都按 `commands/yixiantian.md` 执行。

- **范围**：能看多远、看多细由能力等级决定。初期只能看几天内、与自己直接相关的事【初稿】
- **看到的是可能，不是定数**：给出两三种走向和大致可能性，最终结果仍由判定决定
- **天机遮蔽**：境界远高于主角的人、刻意遮掩天机的人和事、世界深处的秘密，会模糊或看不见
- **伏笔**：一线天的来历与主角的身世和灵根有关，随剧情逐步揭开
- **成长**：之后会被某个玄学门派开发，获得玄学之力，范围和精度随之提升

### 推演（玄学门派）

玄学门派修习的能力，靠星象、卦象、地脉推算天机。与一线天不同：推演是后天学来的学问，要借助器物和推算，耗时，结果常以卦辞、星象的形式给出。
