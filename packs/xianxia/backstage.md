# 幕后规则

亲定事实在存档的 `world/canon.md`，每一条都不可违背，推演和生成都要绕着它设计。

## 由开局秘密生成（玩家不看）

- 主角和养父一起生活的日常（写进序章设计，给玩家亲身感受）
- 主角的真实身份、双胞胎分离的原因、背后的阴谋
- 养父的真实身份、来历、布局、他知道的秘密，以及他与主角身世的关联
- 村庄变故的真相、养父失踪的原因和去向
- 弟弟所属的神秘门派及其在世界三层结构中的位置
- 灵根为何被掩盖、分几个阶段觉醒、每阶段的条件
- 一线天的来历，以及它与身世、灵根的关系
- 真实资质（天资异禀）
- 开发一线天的玄学门派
- 养父线索清单

建议：灵根觉醒和一线天的成长都分阶段，每一阶段绑定机缘或关键剧情节点。风助雷（见规则书），所以完全觉醒后风雷互相增幅，爆发有规则依据。

## 开局填写主角卡

- 真实灵根：`linggen: {风: 至纯, 雷: 至纯}`
- 当前生效：`linggen_active: {风: 寻常}`。规则按它计算，所以前期偏弱；觉醒时逐步提升，最终等于真实灵根
- 世人所见：`linggen_shown: {风: 寻常}`
- 真实资质由开局秘密决定；外人所见 `zizhi_shown: {根骨: 中, 悟性: 中}`
- 一线天：`abilities: [{name: 一线天, level: 1, notes: 只能看几天内、与自己直接相关的事}]`
- 开场是凡人还是已经引气入体，由开局决定
- `player/journal.md` 里不能有身世、弟弟、真实灵根、一线天的来历

## 维护世界时的专属规则

1. **养父之谜**：开局时在 `world/secrets/05-养父线索清单.md` 规划每片碎片：是什么、藏在哪里或由谁讲出、大致在哪一卷出现、揭示到哪一层。之后在合适的地点、人物、时机放出，并在清单里标记。碎片要么体现养父对主角的好，要么透露他是绝世高人，越往后越接近他的身世。
2. **隐藏灵根**：规则按 `linggen_active` 计算；觉醒按 `secrets/` 里定下的条件分阶段进行，觉醒时更新 `linggen_active`，世人察觉时才更新 `linggen_shown`。
3. **人物合规**：灵根、资质、功法、技能、境界都要符合 `rules.md`；功法属性必须与灵根相合（无属性功法除外）；稀有度符合设定，天才要少。
4. **戏剧风格**：遵守 `style_pack.md` 的戏剧规则和风格偏好（尔虞我诈，真情难寻）；揭开秘密前确认 `hooks.md` 里已埋过至少两次线索。
5. **势力**：佛门、道门不是换皮门派，要有真实的思想立场；世界的暗流通常与玄学门派有关。
6. **感情线**：只在主角成年后才能规划，对象必须是成年人。主角未成年期间，时间线、人物卡、伏笔里都不安排任何恋爱或暧昧内容。

## 设计建议

- 灵根觉醒和一线天的成长都分阶段，每一阶段绑定机缘或关键剧情节点
- 风助雷（见 `rules.md`），所以完全觉醒后风雷互相增幅，爆发有规则依据
