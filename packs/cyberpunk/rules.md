# 霓虹深渊·2084 核心规则手册 (`rules.md`)

## 1. 街头阶位体系 (`street_tier`)

在新巴别塔，边缘行者的实力、义体兼容度与街头声望统称为**街头阶位**，共分六个大阶（除`平民`外，每阶细分为 `Lv1` ～ `Lv9`，对应初期/中期/后期/巅峰）：

| 大阶位 | 属性范围 (`attr_range`) | 定位描述 |
|--------|-------------------------|----------|
| **平民** | 1 ～ 3 | 未安装战斗义体的普通底层市民与公司外围雇员 |
| **街头小子** | 2 ～ 5 | 刚踏入地下灰色产业的新秀，搭载民用或翻新改装义体 |
| **老练佣兵** | 4 ～ 8 | 在帮派与中间人圈子里小有名气的好手，能独立应对街头火并或矩阵潜入 |
| **王牌独狼** | 7 ～ 12 | 各大中间人争相雇佣的精英专家，涉足巨型企业间的黑色外包行动 |
| **暗网幽灵** | 11 ～ 17 | 足以撬动城市局势的顶尖危险人物，拥有原型义体或深层黑客权限 |
| **夜城传奇** | 16 ～ 25 | 名字本身就是威慑的都市神话，一举一动牵动顶层权力洗牌 |

---

## 2. 四维核心属性 (`attributes`)

检定修正值按属性与阶位共同折算（上限 `+6`）：

- **肉体**：肌肉力量、抗击打能力、重武器操控与生理耐受上限。
- **反应**：拔枪速度、闪避机动、近身格斗与载具驾驶精准度。
- **算力**：神经接入仓算力、ICE 防火墙突破、敌方义体过载干扰与数据挖掘。
- **酷**：高压环境下的冷静程度、街头威慑、心理博弈、伪装与中间人谈判。

---

## 3. 义体相性 (`chrome_affinity`) 与神经操作系统 (`os_core`)

- **基础相性方向**：`重武 / 义体 / 黑客 / 潜行 / 交涉`
- **异变高阶相性**：`电磁 / 量子`
- **相性兼容度 (`affinity_grades`)**：`民用 < 改装 < 军规 < 原型`
- **神经操作系统 (`os_core`)**：每位角色同一时间只能搭载一套核心神经操作系统，决定其流派倾向（`黑客流 / 义体流 / 枪械流 / 潜行流 / 交涉流 / 综合流`）及所能支撑的最高街头阶位上限（`limit`）。

---

## 4. 义体与装备品级 (`grades` & `gear_tiers`)

- **系统与插件品阶**：`民用 / 改装 / 军规 / 原型`，每阶分 `下品 / 中品 / 上品`（如 `改装上品`、`军规中品`）。
- **随身装备与义体硬件 (`gear_tiers`)**：`街头级 < 改装级 < 军规级 < 企业特供 < 黑墙遗物`。

## 5. 检定难度基准 (2d6 + 修正 vs DC)

| 难度等级 | 目标 DC | 典型场景示例 |

| 普通 | 8 | 在酸雨夜精准射击移动目标、绕过普通门店监控 |
| 困难 | 10 | 突破帮派据点火力封锁、骇入加密的企业物流终端 |
| 极难 | 12 | 正面周旋全副武装的公司特勤小队、攻破军用级黑冰防火墙 |
| 传说 | 14 | 单枪匹马劫走企业原型机甲、潜入巨企顶层核心机房 |
