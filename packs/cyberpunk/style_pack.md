# 霓虹深渊·2099 专属文风手册 (`style_pack.md`)

## 1. 核心感官基调：潮湿、冷硬、霓虹与锈蚀

- **视觉意象**：铅灰色的工业酸雨、积水洼里破碎的全息艺伎倒影、裸露在混凝土墙外的光纤线束、义眼夜视模式下的幽绿微光、枪口迸发的蓝白色电磁电弧。
- **听觉意象**：老旧变压器低沉的电流嗡鸣、远处高架轨道磁悬浮列车的呼啸、合成器低音穿透酒吧铁门的震动、神经接口过载时的尖锐耳鸣。
- **嗅觉与触觉**：臭氧与焦糊电路板的气味、廉价合成威士忌的辛辣、劣质金属义肢在雨夜里的冰冷触感。

## 2. 人物台词与江湖黑话

- 街头人物说话短促、务实、夹杂行业黑话：
  - **信用点 / 欧金 (eb)**：新巴别塔唯一硬通货。
  - **铁皮 / 铬件 (Chrome)**：泛指植入人体的各类义体。
  - **黑冰 (Black ICE)**：矩阵中足以烧毁骇客神经元的致命防御程序。
  - **中间人 (Fixer)**：撮合雇主与边缘行者的地下经纪人。
  - **清道夫 (Scav)**：专门在暗巷袭击路人、拆解活人义体倒卖的底层暴徒。
- 公司高层说话讲究礼貌、克制、满口资产折旧率与风险合规，却在字里行间透出视人命如草芥的冷漠。

## 3. 战斗与潜行描写要求

- 强调**距离感、掩体利用与毫秒级的反应**：枪战不是站桩对射，而是翻滚寻找水泥柱掩护、利用黑客手段使敌方光学义眼短暂雪花屏、在换弹间隙近身夺械的凌厉博弈。
- 受伤与消耗要有实感：子弹擦过防弹衣的钝痛、神经接口超频后鼻腔渗出的温热血丝，都要自然融入动作反馈中。
